# CamCycler project notes

## Purpose

CamCycler is a Blender viewport utility for advancing through scene cameras and toggling **Lock Camera to View** without leaving the 3D viewport.

## README visual guidance

- The registered **Next Camera** shortcut is **Shift + Numpad 0**.
- Demonstrations should use genuine Blender captures and visibly change both the camera view and the active camera row in the Outliner.
- Animated README examples may composite labels, but should cut directly between camera captures so Blender's application frame never slides or ghosts.
- Host README media in `docs/images/` and use an absolute `raw.githubusercontent.com` URL so the image resolves consistently on GitHub.
